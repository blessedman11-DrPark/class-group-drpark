# 박헌규 교수님 과목 조편성/자리배치 프로그램

수업 시간에 학생들을 무작위로 조 편성하고, 강의실 자리를 배치하는 웹 애플리케이션입니다.

## 배포 URL

https://class-group-drpark.vercel.app/

## 주요 기능

### 학생용
- 과목 선택 후 암호 입력하여 접근
- 학생 카드 클릭 시 소속 조 확인 (카드 뒤집기 애니메이션)
- 전체 보기 버튼으로 조별 명단 확인
- 조편성 원칙 확인

### 관리자용 (교수님)
- 교수님 암호로 로그인
- 과목별 학생 명단 등록/수정
- 조당 인원수 설정 (2~10명)
- 조편성 실행 및 초기화
- 자리배치 (아래 참조)
- 과목명 수정
- 과목별 암호 설정
- 교수님 암호 변경

## 자리배치

관리자 패널의 [자리배치] 버튼을 누르면 메인 화면에 자리배치 패널이 펼쳐집니다.

- **학생 명단**: 과목별로 저장됩니다. 저장된 명단이 없으면 해당 과목의 학생 명단이 자동으로 채워집니다.
- **줄 수**: 앞에서 봤을 때 한 줄에 앉는 인원 수입니다. (예: 6 → 한 줄에 6명)
- **자리배치 실행**: 명단을 무작위로 섞은 뒤 앞줄부터 1번 ~ 마지막 번호까지 순서대로 배치합니다.
- **표시**: 줄 수에 맞춰 앞줄부터 채우고, 학생이 없는 자리는 공란 박스로 표시됩니다. 각 자리에는 번호와 그 아래 학생 이름이 나옵니다.
- **자리배치 초기화**: 배치 결과만 지우고 명단은 유지합니다.

배치 결과는 Supabase에 과목별로 저장되므로 다른 기기에서 열어도 같은 결과가 보입니다.

## 조편성 원칙

학생들은 무작위로 섞인 후 각 조에 배정됩니다.

| 조당 인원 | 새 조 생성 기준 | 기존 조 분배 기준 |
|-----------|-----------------|-------------------|
| 3명 | 2명 이상 남았을 때 | 잔여 1명 |
| 4명 | 3명 이상 남았을 때 | 잔여 2명 이하 |
| 5명 | 3명 이상 남았을 때 | 잔여 2명 이하 |
| 6명 | 4명 이상 남았을 때 | 잔여 3명 이하 |

### 예시
- 23명, 3명씩 편성 → 7개조(3명) + 1개조(2명) = **8개 조**
- 9명, 4명씩 편성 → 1개조(4명) + 1개조(5명) = **2개 조**

## 기술 스택

- **Frontend**: HTML, CSS, JavaScript (Vanilla)
- **Backend/DB**: [Supabase](https://supabase.com/) (PostgreSQL + RLS)
- **Hosting**: [Vercel](https://vercel.com/)
- **Version Control**: [GitHub](https://github.com/)

## 보안

- Supabase RLS(Row Level Security) 정책 적용
- 교수님 암호는 RPC 함수를 통한 서버 측 검증
- XSS 공격 방지를 위한 HTML 이스케이프 처리
- 과목별 암호로 학생 접근 제어

## Supabase 테이블 구조

### subjects (과목)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | int8 | PK |
| name | text | 과목명 |
| password | text | 과목 암호 |
| group_size | int4 | 조당 인원수 |

### students (학생)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | int8 | PK |
| subject_id | int8 | FK (subjects) |
| name | text | 학생 이름 |

### group_assignments (조편성)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | int8 | PK |
| subject_id | int8 | FK (subjects) |
| student_id | int8 | FK (students) |
| group_number | int4 | 조 번호 |

### admin_passwords (관리자 암호)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| password_index | int4 | PK |
| password_value | text | 암호 값 |

### seating_arrangements (자리배치)
| 컬럼 | 타입 | 설명 |
|------|------|------|
| subject_id | int8 | PK, FK (subjects) |
| seats_per_row | int4 | 한 줄에 앉는 인원 |
| names | text[] | 저장된 학생 명단 |
| seat_names | text[] | 배치 결과 (1번 자리부터 순서대로) |
| updated_at | timestamptz | 수정 시각 |

생성 SQL은 `supabase/seating_arrangements.sql`에 있습니다. 조회는 누구나 가능하고,
쓰기는 교수님 암호를 검증하는 RPC(`admin_save_seating_list`, `admin_run_seating`,
`admin_reset_seating`)를 통해서만 가능합니다.
